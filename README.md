# MaintAI — Industrial Maintenance Intelligence

O MaintAI é uma aplicação complementar ao SAP, planejada para identificar antecipadamente riscos de atraso ou comprometimento de manutenções programadas devido à indisponibilidade de peças, materiais e componentes.

> **Status:** projeto planejado / em desenvolvimento. Esta documentação descreve o planejamento atual, não funcionalidades necessariamente implementadas.

As duas versões compartilham a mesma estrutura de documentos e identificadores de requisitos/casos de uso. Diagramas comuns ficam em [`docs/diagrams/`](docs/diagrams/README.md). O histórico de alterações está em [`docs/CHANGELOG.md`](docs/CHANGELOG.md).
