# 13. Glossário

| Termo | Definição no contexto do MaintAI |
|---|---|
| Alerta | Registro apresentado pelo sistema quando uma condição de risco ou insuficiência é identificada. |
| Análise de risco | Processo de cruzar ordens, materiais, estoques, reservas, depósitos, prazos e criticidade para identificar possíveis comprometimentos da manutenção. |
| CAP (Cloud Application Programming Model) | Framework previsto para estruturar os serviços e APIs da aplicação. |
| CDS (Core Data Services) | Tecnologia utilizada no planejamento para modelagem de dados e definição de serviços. |
| Criticidade | Atributo do equipamento considerado na avaliação da importância operacional. |
| Déficit | Diferença positiva entre a quantidade necessária e a quantidade disponível para a ordem. |
| Depósito | Local ou unidade de armazenamento de materiais. |
| Dashboard | Interface de acompanhamento de indicadores e situações operacionais. |
| Disponibilidade | Quantidade de material que pode ser considerada livre para atender à necessidade, após os descontos aplicáveis. |
| Equipamento | Ativo industrial ao qual uma ordem de manutenção está relacionada. |
| Estoque físico | Quantidade física registrada de determinado material. |
| Estoque reservado | Quantidade destinada a necessidades identificadas e que não deve ser considerada livre para outras ordens. |
| Fornecedor | Organização associada ao fornecimento de materiais e à informação de prazo de reposição. |
| Manutenção corretiva | Manutenção realizada para tratar uma condição ou falha identificada. |
| Manutenção preventiva | Manutenção planejada para ocorrer antes de uma falha, conforme programação definida. |
| Manutenção programada | Manutenção com data ou período previsto para execução. |
| Material | Peça, componente ou insumo necessário à execução de uma manutenção. |
| MVP (Minimum Viable Product) | Primeira versão priorizada para validar o fluxo principal do MaintAI. |
| Ordem de manutenção | Registro que representa uma atividade de manutenção, seu equipamento, data, status, prioridade e materiais necessários. |
| Prioridade | Classificação de importância atribuída a uma ordem de manutenção. |
| Recomendação | Alternativa sugerida pelo MaintAI para avaliação do responsável. |
| Reserva | Quantidade de material destinada a uma necessidade específica. |
| SAP ERP | Sistema de gestão empresarial considerado como possível fonte de dados para integração futura. |
| SAP Fiori | Tecnologia / experiência de interface prevista para a aplicação web. |
| SAP HANA Cloud | Banco de dados previsto para uma etapa posterior do projeto. |
| SAP S/4HANA | Plataforma SAP considerada como possível fonte de dados para integração futura. |
| SAPUI5 | Tecnologia prevista para construção da interface web. |
| SQLite | Banco de dados previsto para desenvolvimento local e testes iniciais. |
| Transferência | Movimentação de material entre depósitos, apresentada pelo MaintAI apenas como alternativa para avaliação no MVP. |

## Observação

As definições descrevem o uso dos termos neste projeto. A nomenclatura e os conceitos poderão ser refinados conforme o modelo de dados e os processos forem detalhados.
