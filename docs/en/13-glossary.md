# 13. Glossary

| Term | Definition in the MaintAI context |
|---|---|
| Alert | A record presented by the system when a risk condition or shortage is identified. |
| Risk analysis | The process of correlating orders, materials, stock, reservations, storage locations, lead times, and criticality to identify potential maintenance execution issues. |
| CAP (Cloud Application Programming Model) | Framework planned for structuring the application's services and APIs. |
| CDS (Core Data Services) | Technology planned for data modeling and service definitions. |
| Criticality | Equipment attribute considered when assessing operational importance. |
| Shortage | Positive difference between the quantity required and the quantity available for an order. |
| Storage location | Place or organizational unit where materials are stored. |
| Dashboard | Interface for monitoring operational indicators and situations. |
| Availability | Quantity of material that may be considered free to meet a requirement after applicable deductions. |
| Equipment | Industrial asset associated with a maintenance order. |
| Physical stock | Recorded physical quantity of a given material. |
| Reserved stock | Quantity assigned to identified requirements and not considered freely available to other orders. |
| Supplier | Organization associated with material supply and replenishment lead-time information. |
| Corrective maintenance | Maintenance performed to address an identified condition or failure. |
| Preventive maintenance | Planned maintenance intended to take place before a failure, according to a defined schedule. |
| Scheduled maintenance | Maintenance with an expected execution date or period. |
| Material | Part, component, or supply required to perform maintenance. |
| MVP (Minimum Viable Product) | First prioritized version intended to validate the main MaintAI workflow. |
| Maintenance order | Record representing a maintenance activity, its equipment, date, status, priority, and required materials. |
| Priority | Importance classification assigned to a maintenance order. |
| Recommendation | Alternative suggested by MaintAI for evaluation by a responsible person. |
| Reservation | Material quantity assigned to a specific requirement. |
| SAP ERP | Enterprise management system considered as a possible future data source. |
| SAP Fiori | Interface technology / experience planned for the web application. |
| SAP HANA Cloud | Database planned for a later project stage. |
| SAP S/4HANA | SAP platform considered as a possible future data source. |
| SAPUI5 | Technology planned for building the web interface. |
| SQLite | Database planned for initial local development and testing. |
| Transfer | Movement of material between storage locations, presented by MaintAI only as an alternative for evaluation in the MVP. |

## Note

These definitions describe how the terms are used in this project. Terminology and concepts may be refined as the data model and processes are detailed.
